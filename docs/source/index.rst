EnsgSearch Documentation
=========================

This repository contains lessons on how to use `OpenSearch <https://opensearch.org/docs/latest/about/>`_
as a document database.

It is organized into three sessions:

1. **Session 1** – How to install OpenSearch using Docker Compose
2. **Session 2** – A comparison between Python data manipulation and equivalent usage with OpenSearch
3. **Session 3** – A hands-on use case to complete yourself
